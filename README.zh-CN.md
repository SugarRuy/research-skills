# Research Skills

[English](README.md) | [简体中文](README.zh-CN.md)

面向科研与科学写作的实用 skill 集合。每个模块处理一个明确任务，可以独立使用，也可以接入更大的科研流程。Skill 指令使用英文；评估报告可以按你的要求使用中文或其他语言。

第一个模块帮助研究者判断论文是否准备好投稿，以及还需要修改什么。

## 现有模块

| Skill | 适用场景 | 输出 |
| --- | --- | --- |
| [Paper Submission Acceptance](skills/paper-submission-acceptance/SKILL.md) | 已有稿件，需要判断投稿就绪程度、明确修改重点，或复查已完成的修改。 | 有依据的就绪判断、实质阻塞项、收尾工作、未核验事项，以及具体完成条件。 |

## 论文投稿就绪评估

论文修改了很多轮，仍然不知道能否投稿。新一轮检查又增加了建议，却没有说明哪些必须完成、什么时候可以停止修改。

这个 skill 从研究问题、贡献、论证、证据、可读性和最终材料出发，判断哪些问题需要实质修改、哪些可以进入收尾，以及哪些部分已经达到要求。

评估重点包括：

- **正文证据可核查。** 正文中有实质论证作用的数字应展示在主图表中，或能从展示值透明推导。如果一项次要数字结果移到附录，依赖它的详细解释也应一起移动。设计数量、数学常数和示例阈值不自动视为结果估计。
- **问题有完成条件。** 每项影响判断的发现包含位置、证据、对就绪程度的影响，以及解决条件。材料缺失应标为未核验，不凭空判为失败。
- **修改能够收敛。** 多轮检查保留已经解决的决定；只有新证据、相关稿件修改或实际矛盾才重新打开问题。局部措辞偏好不应让实质修改重新开始。

报告首先给出一种状态：

| 状态 | 含义 |
| --- | --- |
| 需要实质修改 | 已发现的问题使核心主张无法被评估或支持。 |
| 可以进入收尾 | 研究和论证已经稳定，剩下范围明确的呈现或材料工作。 |
| 可以投稿 | 当前检查版本通过实质标准和适用的最终检查。 |
| 尚未充分核验 | 材料或检查缺失，暂时无法给出完整判断。 |

评估本身不会提交或修改稿件，也不预测录用结果。如果你同时要求修复问题，skill 支持完成已授权的修改。

## 本地使用

将完整的 `skills/paper-submission-acceptance/` 文件夹复制到所用 agent 支持的 skill 目录，或让 agent 读取其中的 `SKILL.md`。该模块不依赖其他 skill 或脚本。文件读取、PDF 查看和搜索工具的可用性决定哪些检查能完成；无法执行的检查必须标为未核验。

提供当前稿件、相关图表和附录。最终核验还需要实际渲染的 PDF 和适用的投稿要求。复查时可附上上一轮发现。材料不完整时也可以开始，但判断会注明覆盖范围。

调用示例：

- “使用 paper-submission-acceptance 评估这篇稿件，区分实质问题与收尾工作。”
- “检查正文讨论的实质数字是否有正文图表支持。”
- “结合本次修改复查上一轮问题；不受修改影响的已解决事项保持关闭。”
- “现在能否停止实质修改？说明还有什么影响就绪判断。”

两个虚构示例展示具体评估方式：

- [可以从主表透明推导的结果](examples/submission-readiness.md)：区分措辞收尾与尚未核验的最终检查。
- [数字证据只在附录中](examples/missing-main-text-evidence.md)：识别未满足的展示要求，并在不凭空要求新实验的前提下解决问题。

示例用于说明行为，不代表实测效果。

## 在科研流程中的位置

完成初稿或修改后，只要需要就绪判断，就可以使用这个模块。它可以与写作、证据核验和投稿材料检查工具配合，不要求特定 skill 家族或固定执行顺序。

后续任务明确后，再向 `skills/` 添加模块。每个模块应说明适用场景、输出，以及完成条件。
