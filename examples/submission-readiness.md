## Required finishing work

**Evidence:** The relative reduction is transparently derivable: `(25 - 22) / 25 = 12%`. The absolute reduction is 3 percentage points. Both displayed rates describe the same eligible population and aggregation.

**Effect on readiness:** The evidence-display requirement is satisfied; ambiguous wording is a bounded presentation issue. No new experiment or duplicate table is needed.

**Completion condition:** Identify the result as a relative reduction, retain the Table 2 reference, and use compatible units throughout the discussion.
